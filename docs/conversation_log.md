## 轮次 14：STL 布尔与穿模修复

**需求**：「你这建模有问题啊，咋既穿模又布尔有问题」。

**问题定位**

- 旧版 `end_cap_with_holes()` 是「环形盘 + 4 个孔壁圆筒 + 端面扇形封堵」，没有做实体减法：孔壁与盘体共存，导出的端盖 `split()` 后是 5 个 body（穿模）
- `hole_in_plate()` 只生成孔壁圆筒，从未从板件中减料，孔实际上是假的
- 倒角是另贴一层锥面壳，与本体重叠
- 鼻锥母线公式方向写反：`sqrt(rho²-(L-x)²)-(rho-r0)` 在尖端得 r=27，几何自交
- 尾翼滑板孔位传参把 x 当成 y，孔落到 y=0 的边缘；肋条只有 3mm 宽却要打 Ø4.4 孔，孔直接破边；尾锥环形槽深 3.2mm，把 2mm 壁切穿

**修复内容**

- `sim/stl_v2_detail.py` 整体重写为 `trimesh` + `manifold3d` **真布尔**：端盖/肋条/滑板/楔块用 `difference` 减孔，尾锥/传感板用回转体减槽，鼻锥用外卵形减内卵形
- 新增 `radial_holes()` 支持锥体局部外径（`r_local`），避免径向孔按错误基圆定位
- 新增 `cone_groove()`：槽随内锥面走，深 0.8mm，保留 1.2mm 壁
- 鼻锥改为正确的切线卵形 `r(x)=sqrt(rho²-x²)+R-rho`（x∈[0,216]，尖端 r→0），内腔向 x<0 延伸保证底部开口
- `plate()` 增加 `poly.is_valid` 校验：孔越界时 shapely 会静默丢孔，现在直接报错
- `emit()` 强制校验 `is_watertight` 且 `split()==1`，不满足即 `RuntimeError`
- 修正端盖螺纹规格（助推 4×M5 底孔 Ø4.2 @ BCD65；续航 4×M4 底孔 Ø3.3 @ BCD45）、伞舱两孔改为 180° 对穿、肋条 3→10mm 宽
- 射线实测 14 处通孔全部贯通；副产物：质量密度单位错误（g/mm³ 当 g/cm³）修正，总质量由 0.8 g 恢复为 931.9 g
- 重新渲染 `figures/rocket_3d.png`、`figures/parts_3d.png`（取消随机抽面，鼻锥不再呈点云；排布改为尾→头顺序）

**结果**：13 种 / 19 件，全部 `watertight=True` 且单壳体；单件体积合计 352.6 cm³，总质量 **931.9 g**，三角面 63,908。

**复核（同日）**：逐件用解析体积对照（端盖/尾锥/尾翼/滑板/肋条/脐带舱/传感板/伞筒/楔块偏差均 <0.5%），检查 `is_volume`、绕向一致性、欧拉示性数（通孔数与亏格一一对应）。据此发现鼻锥内外卵形在 x=216 收于同一点，尖端壁厚为零、欧拉数为奇数（非流形接触）；已改为尖端留 8mm 实心，欧拉数恢复为 -2（底部开口 + 2 个排气孔 = 亏格 2）。15 条射线复验：14 处通孔全部贯通，鼻锥轴线命中内腔端面 x=208 与顶点 x=216，确认尖端已封闭。

**复核（第二轮）**：按「孔径 vs 配合件」逐项核对，又发现两处尺寸矛盾——

- 脐带舱 Ø5.2（M6 底孔）开在 2.5mm PETG 壁上：M6 螺钉（Ø6）根本穿不过，2.5mm 壁也无法攻丝。改为 Ø6.6 通孔 + 背面 M6 螺母。
- 喷管保持环原 Ø66/Ø58，说明书写「内孔 Ø58 与喷管外径配合」，但喷管最大外径仅 Ø32；Ø66 又与机匣内径 Ø58.2 冲突，该件与任何零件都配不上。改为定心环 Ø58/Ø32.4（配机匣内径 Ø58.2、喷管外径 Ø32），并明确喷管轴向由高温环氧粘接承力。

**当前指标**：13 种 / 19 件，单件体积合计 358.5 cm³（按件数 525.9 cm³），总质量 **948.3 g**，三角面 64,100；17 条射线复验全部通过。

## 轮次 16：环境目录改名，修掉快照不保留的问题

**现象**：轮次 15 建的 `.venv/` 在下一轮沙箱启动后消失（仓库其他文件都在）。

**根因**：工作区持久化是 restic 快照（`/var/log/tool/agent-tool-host.stdout.log` 中 `restic_restore ... workspace=/workspace`），其忽略列表 `/app/etc/.resticignore` 明确排除了 `.venv`、`node_modules`、`__pycache__`、`.pytest_cache` 等目录——`.venv` 从一开始就没进备份。

**做法**

- 环境改建在仓库内 `env/`（不在忽略列表里），仍写进 `.gitignore`，只随快照保留、不进 Git
- torch 改用官方 CPU 轮子（`torch==2.12.1+cpu`，requirements.txt 里加 `--extra-index-url https://download.pytorch.org/whl/cpu`），环境从 5.0 GB 降到 1.2 GB，也减少每轮快照体积
- README 复现节命令统一改为 `env/bin/python`，并注明为什么不能叫 `.venv`

**验证**：`env/bin/python` 跑通 STL（948.3 g / 64,100 面 / 全部水密）、渲染、FEA（SF_min 7.63、一阶 32.4 Hz），数值与前两轮环境完全一致。
