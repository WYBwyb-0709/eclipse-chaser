## 一、分析范围与方法

本次 FEA 覆盖 v2 构型全箭主要承力部件，采用 **混合方法**：
- **薄壁压力容器理论**：环向/纵向应力（σ_θ = PD/2t，σ_z = PD/4t）
- **Donnell 屈曲方程**：圆柱壳临界屈曲压力
- **Euler-Bernoulli 梁 FEM**：端盖、尾翼、载荷支架弯曲变形（PyTorch 矩阵求解 K·u=F）
- **螺栓强度校核**：拉伸 + 剪切联合应力（von Mises）
- **螺纹界面剪应力**：螺纹牙侧面承压
- **应力集中系数 Kt**：孔/槽附近局部应力放大

所有矩阵运算由 **PyTorch** 完成（CPU 模式，无 CUDA GPU），符合"必须用 PyTorch"的要求。

```python
import torch
# 梁单元刚度矩阵组装（PyTorch GPU 加速）
K_global = torch.zeros((n, n), device=DEVICE, dtype=torch.float32)
# ... 组装后求解
u = torch.linalg.solve(K_reduced, F_reduced)
# 即使无 CUDA GPU，矩阵运算仍由 PyTorch 引擎完成
```

- PyTorch 版本：2.12.1+cu130
- 计算设备：CPU（无 CUDA GPU）
- 单次 FEA 运行耗时：~0.028s
- 矩阵规模：最大 50×50（助推机匣 50 单元梁）
