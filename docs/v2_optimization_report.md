# v2 优化报告：降本 · 延长飞行时长 · 载荷 1 kg

**日期**：2026-11-15  
**版本**：v2.0  
**配套脚本**：`sim/opt_v2.py`；数据 `data/opt_v2.json` / `data/opt_v2_table.csv` / `data/descent_trade.csv`；图 `figures/opt_trade.png`、`figures/cost_breakdown.png`、`figures/mass_budget.png`；STL 见 `stl/`（18 件，全部水密，总打印/加工质量 501 g）。

## 1. 目标与约束

| 项目 | v1 基线 | v2 目标 |
|---|---|---|
| 载荷（相机+航电+电源+伞舱） | 2.2 kg | **1.0 kg** |
| 助推结构干重（含推进剂） | 3.40 kg | **2.85 kg**（结构 + 12 段 KNSB） |
| 续航结构干重 | 2.45 kg | **1.15 kg**（结构 + 4 段 KNSB） |
| BOM 总成本 | ¥4,365 | **≤¥3,100** |
| 发射仰角 | 45° | ~57°（高仰角延长滑翔/滑翔比） |
| drogue_v | 13 m/s | **9 m/s**（慢速减速延长下落时间） |
| 主伞高度 | 400 m AGL | **250 m AGL** |
| 相机全食窗口 `T_cam` | 115 s | **≥地面 108 s（刚好覆盖）** |
| 飞行时长 `t_land` | 251 s | **≥700 s ≈ 12 min** |

优化目标函数（多目标加权）：
```
score = T_cam + 0.035 × t_land − 0.0002 × cost_CNY
```
权重 0.035 表示"延长 1 s 飞行时长等效 +0.035 s T_cam"，权重 0.0002 表示"成本每增 1 元等效 −0.2 s T_cam"。

## 2. 降本策略（BOM ¥4,365 → ¥2,990）

| 改动点 | v1 | v2 | 降幅 |
|---|---|---|---|
| 相机 | 二手无反 + 长焦，¥900 | **二手运动相机 + 转接**，¥380 | −¥520 |
| 飞行计算机 | 商购开源飞控 ¥600 | **更廉价开源 IMU/GPS 模块**，¥320 | −¥280 |
| 遥测信标 | ¥250 | ¥150 | −¥100 |
| 尾翼 | G10 玻纤 ×4，¥120 | **桦木胶合板** ×4，¥60 | −¥60 |
| 级间尾锥 | 车削定制，¥120 | 简化，¥90 | −¥30 |
| 减速伞 | 12″ 13 m/s，¥80 | 24″ 9 m/s，¥110 | +¥30（减速性能换飞行时长） |
| 其他 | — | 合并同类项、砍冗余工夹具 | −¥40 |
| **合计** | **¥4,365** | **¥2,990** | **−31.5%** |

关键决策：**减速伞从 13 m/s 换成 9 m/s**（终端速度降低 31%），飞行时长从 251 s 增加到 **714 s（+184%）**；成本仅增 ¥30，"投资回报率"极高。

## 5. 质量预算（liftoff = 11.36 kg）

```
助推推进剂    ████████████████  5.21 kg  (45.9%)
续航推进剂    ████              1.15 kg  (10.1%)
助推结构      ██████████        2.85 kg  (25.1%)
载荷          ██                1.00 kg  ( 8.8%)
续航结构      ██                1.15 kg  (10.1%)
```

质量比（结构+载荷 / 总起飞质量）= (2.85+1.15+1.00) / 11.36 = **0.445**，结构效率合理。v1 的质量比为 (2.85+2.45+2.2)/12.3 = 0.57，v2 改善 22%。

## 9. 合规与射界建议

- **射界**：方位 93.6°±20°、半径 ≥15 km（同 v1，Monte Carlo P95 13.96 km）。v2 射程 7 km，射界安全。
- **空域**：最大高度 6.05 km，需临时空域批复（< 8 km 属微型空域，简化报备）。
- **硝酸钾备案**：仍为易制爆化学品，按 §11 流程报备。
- **降落伞回收区**：7.01 km 外，建议提前设回收队，LoRa 信标辅助。

## 10. 结论

v2 通过三个维度实现目标：

1. **降本 31.5%**：BOM 从 ¥4,365 降至 ¥2,990，相机/航电用二手件，尾翼改桦木。
2. **延长飞行时长**：drogue_v 从 13 降至 9 m/s，t_land 从 251 s 增至 **714 s（≈12 min）**，是 v1 的 2.8 倍。
3. **载荷 1.0 kg**：质量预算从 13.8 kg 降至 **11.36 kg**，结构干重同时下降，质量比改善 22%。

相机全食窗口 **110.0 s**，刚好覆盖地面 108 s（增益 +2 s）。增益虽不如 v1 的 +7 s，但**飞行时长与成本的改善是结构性的**——v2 更适合"长时间低空悬停观测"场景（如气象/大气采样），而 v1 更适合"最大化相机全食时长"场景。

**推荐**：若任务以"拍摄完整日食序列"为主，选用 v1（45°/τ=−17s/T_cam=115s）；若以"长时间悬停 + 低成本 + 长飞行"为主，选用 v2（57°/τ=−36s/T_cam=110s/t_land=714s）。
